Customer process

How a C&C ZF 8HP Build Starts

C&C needs enough information to identify the transmission and understand the car. From there, the customer process is four steps.

  1. 01

    Send the combination

    Start with the vehicle, engine setup, intended use, current power, target power, and a clear photo of the transmission tag.

  2. 02

    C&C checks the unit

    The model name is matched to the tag, part number, drivetrain, donor history, and the condition information you can provide.

  3. 03

    C&C recommends the build

    Parts and related needs are discussed around the car. Converter, TCU calibration, cooling, and existing damage can change the recommendation.

  4. 04

    Approve the written quote

    The quote is where parts, price, timing, shipping instructions, and warranty terms become specific to the job.

Before parts are selected

What C&C checks first

C&C checks weight, tire, torque delivery, launch behavior, converter, TCU calibration, cooling, and current transmission condition before recommending parts.

Step one

Tell C&C about the car.

Start with the tag, vehicle, engine, current output, target output, use, and current transmission problems.
