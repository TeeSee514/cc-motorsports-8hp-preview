What C&C Needs Before Recommending an 8HP Build

Start with the transmission tag, vehicle, engine combination, controls, cooling, tire, and how the car is used.

Have these details ready

Good photos and exact identifiers are more useful than a guessed transmission code.

Vehicle

  • Year, make, and model
  • Chassis code
  • RWD or AWD
  • Vehicle weight, if known

Transmission

  • Tag photo
  • Part number
  • Diagnostic identification
  • Donor vehicle and current condition

Engine and power

  • Engine combination
  • Turbo or supercharger setup
  • Fuel
  • Current and target output, if known

Use and controls

  • Street, roll, or drag use
  • Tire and launch behavior
  • Converter
  • TCU calibration and cooling

The transmission tag is the best place to start.

Send a sharp, readable photo of the tag and include any diagnostic identification you already have. If the unit came from another car, include the donor details too.

C&C can then tell you what other information is needed for that combination.
