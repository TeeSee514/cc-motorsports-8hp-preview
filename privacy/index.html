Development privacy notice

No Real Customer Data Belongs in This Staging Site.

This notice describes the implemented local dry-run—not a future production intake. The current endpoint is disabled by default and, when explicitly enabled for tests, accepts only acknowledged synthetic data.

● CHRIS TO CONFIRMLegal and business owners must approve a production privacy notice, contact route, retention schedule, provider list, and rights process.

CURRENT IMPLEMENTATION

Local development only · Updated August 12, 2026

1. Current staging behavior

Form delivery is disabled unless a developer explicitly sets ENABLE_FORM_TEST_MODE=true. Even then, the server requires an acknowledgement that every value and upload is noncustomer synthetic test data.

A valid dry-run is parsed, validated, and discarded in request memory. The implementation does not write a file, database row, cookie, session, local-storage value, or shop notification. It does not send email or SMS and does not log submitted values.

2. Data fields present for testing

The form model contains contact, location, vehicle, transmission, performance, calibration, tire, use, condition, package, logistics, timeframe, notes, consent, and optional evidence-upload fields. Their presence describes a proposed intake—not authorization to collect real information.

3. Tracking and browser storage

This site contains no analytics, advertising pixels, third-party fonts, remote images, third-party scripts, or trackers. The form does not use local storage. The current implementation creates no application cookies or sessions.

4. Upload controls

The server permits only PDF, JPG/JPEG, PNG, or WebP dry-run files, with a 5 MB per-file limit and 15 MB combined limit. It validates MIME type, extension, size, count, empty files, and bounded filenames. Accepted synthetic files are discarded immediately.

5. Production requirements

Before accepting real customer information, C&C must approve the data controller identity, purposes, lawful basis where applicable, required and optional fields, consent language, processors, hosting region, access controls, retention and deletion, incident handling, customer rights, upload handling, and a working privacy contact route.

● CHRIS TO CONFIRMApprove every production data practice and publish an accurate, jurisdiction-appropriate notice before enabling delivery.

6. Contact

No privacy inbox, public email, or canonical phone number has been approved for this project. Do not submit real data and do not use this staging site to make a privacy request.

● CHRIS TO CONFIRMApprove a monitored privacy contact route and response process.
