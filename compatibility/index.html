REVIEW POLICY

What a “Requires Review” State Means

It is a candidate record for intake—not confirmation that C&C accepts the vehicle, that a listed component fits, or that one transmission can interchange with another.

Approval requires exact vehicle and transmission identity, intended use, current condition, torque and output goals, calibration, drivetrain, tire, service format, and any evidence C&C requests.

The generic “Not currently offered” row demonstrates a reject state without falsely attributing rejection to a specific real vehicle.
